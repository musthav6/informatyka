# Інформатика · Вінницький ліцей №2

Сайт для учнів 5–7 класів: https://musthav6.github.io/informatyka/

На кожен урок є сторінка `?l=<клас>-<номер уроку>` (наприклад, `?l=5-05`). На ній спершу коротка теорія з визначеннями, далі практика: практична робота, тренажер або оцінюваний тест. На цю сторінку веде QR-код уроку.

## Що є на сайті
- **Тренажери** — для самоперевірки, 2 спроби, після кожної відповіді одразу видно, чи вона правильна.
- **Діагностувальні й тематичні** — оцінювані, 1 спроба, 20 хв, результат наприкінці.
- **Практичні роботи** — кроки з галочками окремо для комп'ютера і для телефона, критерії на 12 балів.
- **QR-коди** — `qr.html` (усі уроки, для друку) і `qr.html?l=5-05` (один на весь екран, для проєктора).

## Код уроку
Тренажери, практичні й діагностувальні відкриваються лише після коду, який учитель називає на уроці.
- **Код = слово вчителя + поточна година за Києвом.** Якщо слово «zorya», то о 9:20 код — `zorya9` (або `zorya09`), о 14:05 — `zorya14`. Підходить і година до та після (±1). Великі літери й пробіли не важать.
- У `config.js` зберігається лише хеш слова (`LESSON_CODE_HASH`), саме слово в коді сайту відсутнє. Нове слово: `teacher.html` → «Код уроку».
- Тренажери й практичні: код вводиться один раз на уроці, далі урок на цьому пристрої відкритий (для домашки теж).
- Діагностувальні й тематичні: код діє 90 хв, потім треба ввести знову — щоб не проходили вдома наперед.
- Пароль учителя теж підходить як код. `LESSON_CODE_HASH: ""` — вимкнути коди взагалі; `LESSON_CODE_FOR` — де саме вимагати.

## Як працюють тести
- **Варіанти:** кожне запитання має 2–3 варіанти, учень отримує випадковий набір; порядок запитань і відповідей перемішується. На повторній спробі варіанти інші.
- **Вихід із вкладки** (інша вкладка, згортання, перезавантаження, PrintScreen) — поточне запитання згорає. Після `MAX_VIOLATIONS` виходів (`config.js`) тест завершується.
- **Спроби:** у кожному тесті поле `attempts`. Коли спроби скінчилися, учитель вводить пароль — і учень отримує ще одну.
- **Результати** йдуть у Google Таблицю: клас, учень, спроба, бали, оцінка за 12-бальною шкалою, виходи з вкладки, номери помилок. Пристрої учнів не відстежуються.

## Налаштування за 5 хвилин
1. Settings → Pages → Deploy from branch: `main`, папка `/ (root)` → Save. За хвилину-дві сайт відкриється за адресою вище.
2. Створи Google Таблицю → Розширення → Apps Script → встав `apps-script/Code.gs` → Зберегти.
3. Розгорнути → Нове розгортання → тип «Веб-застосунок» → Виконувати як: **я**, Доступ: **усі** → Розгорнути → скопіюй URL.
4. Встав URL у `config.js` → `SHEETS_URL`.
5. Відкрий `teacher.html`, введи новий пароль, скопіюй рядок `TEACHER_HASH` у `config.js`. (Тимчасовий пароль: `Inform2026` — заміни.)

## Новий урок
1. Додай запис у `lessons.js`: номер і тема — строго за КТП, визначення — з конспекту.
2. Тренажер: скопіюй будь-який файл із `tests/`, зміни `id`, `grade`, `lesson`, `title`, `slots`, додай ім'я файлу в `tests/index.js`.
3. Практична (за потреби): файл у `practice/` + рядок у `practice/index.js`.
4. QR-коди: `pip install segno && python3 tools/make_qr.py`.

Формати завдань у тестах:
- `["Питання", ["правильна", "хибна", "хибна"], "пояснення"]` — одна відповідь (правильна завжди перша, на екрані перемішується)
- `{ q, ok: [...], no: [...], x }` — кілька правильних
- `{ q, input: ["варіант1", "варіант2"], hint, x }` — введення з клавіатури
- `{ q, tf: true|false, x }` — так/ні

## Обмеження (чесно)
Захист від списування клієнтський: пароль зберігається як хеш, але кмітливий учень може відкрити сайт в іншому браузері чи з іншим іменем. Тому дивись у таблицю: стовпець «Спроба» і час показують такі випадки.
