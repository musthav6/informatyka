# Тести з інформатики (GitHub Pages)

Статичний сайт: `index.html` — перелік тестів по класах, `test.html?t=<id>` — сам тест, `teacher.html` — панель учителя.

## Як працює
- **Варіанти:** кожне запитання має 2–3 варіанти, учень отримує випадковий набір; порядок запитань і відповідей перемішується. На повторній спробі варіанти інші.
- **Вихід із вкладки** (інша вкладка, згортання, перезавантаження, PrintScreen) — поточне запитання згорає. Після `MAX_VIOLATIONS` виходів (config.js) тест завершується.
- **Спроби:** у кожному тесті поле `attempts` (діагностувальні — 1, тренажери — 2). Коли спроби скінчилися, учитель вводить пароль — і учень отримує ще одну.
- **Результати** йдуть у Google Таблицю: клас, учень, спроба, бали, оцінка за 12-бальною шкалою, виходи з вкладки, номери помилок, ідентифікатор пристрою (видно, якщо з одного телефона писали кілька «учнів»).

## Налаштування за 5 хвилин
1. Створи Google Таблицю → Розширення → Apps Script → встав `apps-script/Code.gs` → Зберегти.
2. Розгорнути → Нове розгортання → тип «Веб-застосунок» → Виконувати як: **я**, Доступ: **усі** → Розгорнути → скопіюй URL.
3. Встав URL у `config.js` → `SHEETS_URL`.
4. Відкрий `teacher.html`, введи новий пароль, скопіюй рядок `TEACHER_HASH` у `config.js`. (Тимчасовий пароль: `Inform2026` — заміни.)
5. Закомітити все в репозиторій → Settings → Pages → Deploy from branch `main` / root.

## Новий тест
Скопіюй будь-який файл із `tests/`, зміни `id`, `title`, `slots`, додай ім'я файлу в `tests/index.js`.
Формати завдань:
- `["Питання", ["правильна", "хибна", "хибна"], "пояснення"]` — одна відповідь
- `{ q, ok: [...], no: [...], x }` — кілька правильних
- `{ q, input: ["варіант1", "варіант2"], hint, x }` — введення з клавіатури
- `{ q, tf: true|false, x }` — так/ні

## Обмеження (чесно)
Захист від списування клієнтський: пароль зберігається як хеш, але кмітливий учень може відкрити сайт в іншому браузері чи з іншим іменем. Тому дивись у таблицю: стовпці «Пристрій» і «Спроба» показують такі випадки.
